# 03. Пайплайн машин

Скачанные модели — основной путь новых машин. Цель: рецепт, по которому Sonnet на средних рассуждениях добавляет машину без помощи владельца, а тесты сами говорят, хороша ли она.

## Что сейчас не так

- Либо стоят оригинальные шины модели без деформации и без связи с физикой, либо наши шины: со связью, но визуально низкого качества.
- Подвеска под машиной — наши общие детали по типу оси, а не детали самой модели (кроме БТР).
- Салон скачанных машин чёрный: из кабины ничего не видно. У Defender салон нормальный: это главная улика (его салон — наша геометрия с нашими материалами, а скачанным мы всем деталям включаем отбрасывание и приём теней и меняем стёкла).
- Позиции лучей фар скачанных машин заданы руками.
- У Defender область под арками плохая: текстуры наслаиваются, подвеска уходит непонятно куда.
- Физика каждой машины подобрана на глаз, на скорости машины почти неуправляемы.
- G-Class и Lancia сидят на неразрезных мостах, хотя у реальных независимая подвеска (общий код её умеет: нужно перенастроить крен и проверить тестами управляемости).

## Целевой результат для каждой машины

1. **Оригинальные шины и диски** модели, но:
   - шина деформируется нашим шейдером по данным физики (пятно, обхват препятствий, давление, см. `02-physics.md`);
   - радиус и ширина для физики измеряются с меша автоматически;
   - диск и тормозной механизм отделены от шины: шина мнётся, диск нет.
2. **Подвеска под машиной** собрана из библиотеки готовых деталей (мост, рычаги, пружины, рессоры, амортизаторы, тяги, валы, ШРУСы) под тип подвески машины, по её реальной колее и базе, и анимируется физикой. Подвеска из модели скрывается или используется, если она хорошая.
3. **Подкрылки и днище**: автоматически закрываем дыры в арках и под машиной тёмной геометрией, чтобы не было видно насквозь.
4. **Салон** видно днём и ночью: исправленные материалы, подсветка салона (отдельная заполняющая подсветка или зонд освещения внутри кабины), стёкла без лишнего затемнения. Приборы и подсветка приборов, где возможно.
5. **Фары и фонари**: позиции берутся по мешам линз автоматически, линзы светятся (emissive), лучи как в `05-graphics.md`.
6. **Физика из реальных данных**: масса, габариты, мотор (кривая момента), коробка, главная пара, раздатка, дифференциалы, тип подвески по осям, шины, тормоза. Агент ищет данные в интернете.
7. **Настройка из целей** (`02-physics.md`) и тестовый набор с порогами.
8. **Звук мотора** под конфигурацию этого мотора (`07-audio.md`).

## Рецепт

Пошаговый рецепт для агента, со всеми местами, где у машины есть данные, и с проверками и порогами: `.claude/skills/add-car/SKILL.md`. Ниже — целевой пайплайн, к которому он движется.

1. **Выбор модели.** Критерии: колёса отдельными объектами или отделимы, разумное число треугольников (до ~150 тыс.), текстуры PBR, есть салон. Лицензия желательно открытая, автора указываем в титрах.
2. **Скачивание.** Sketchfab API (ключ у владельца, путь записан в DEVNOTES.md) или другой источник.
3. **Подготовка автоматическим инструментом** (развитие `tools/prepcar.mjs`):
   - масштаб в метры, система координат игры (+x вправо, +y вверх, −z вперёд);
   - поиск колёс, разделение на шину, диск, тормоз;
   - замер базы, колеи, размеров шин, габаритов;
   - контур кузова → коллайдеры (набор боксов, подогнанных к форме);
   - поиск линз фар и фонарей, стёкол, салона;
   - исправление материалов (стёкла, салон, линзы);
   - сжатие (meshopt, WebP), уровни детализации для дальних дистанций и машин друзей.
4. **Данные машины** (один файл на машину): характеристики, тип подвески по осям, дифференциалы, цели настройки, камеры (кабина, капот, преследование), источник и автор.
5. **Сборка подвески** из библиотеки деталей по типу подвески.
6. **Тесты** (`02-physics.md`, раздел «Тесты»). Пороги по реальным данным машины.
7. **Набор скриншотов для проверки**: сбоку, 3/4, из кабины днём, из кабины ночью, снизу (подвеска), фары ночью, на трейле.
8. **Регистрация**: одна запись о машине. Меню, настройки и титры строятся из неё. Сейчас список машин уже живёт в двух связанных местах (`CARS` и `CAR_SPECS`), и игра не запустится, если они разойдутся.

## Что уже сделано (6 октября: машина — это данные)

- Всё о машине в одном файле `src/cars/<id>.js` (физика, вид, пороги тестов), формат в `src/cars/README.md`. Дефендер — обычная машина. Один сборщик параметров для любого числа осей и типов подвески (`vehicle/carParams.js`), один сборщик вида (`vehicle/model/index.js`).
- Привод: постоянный полный, подключаемый полный, задний, передний (`drive.layout`), тест `npm run simtest layouts`. Подвеска по оси: мост, двойные рычаги, стойка (`axles[i].type`, `linkage`), тест `npm run simtest suspension`.
- Вид собирается из общих деталей по данным: колёса модели или наши, мост, независимая подвеска (своя модели или нарисованная), фары по ролям, люстра на крыше, руль и рычаги салона из узлов модели, башня.
- `tools/cutparts.mjs` вырезает детали из готовой модели (руль, стёкла фар); `tools/rigview.html` меряет арки (`measureArches()`) и показывает варианты машины (`?patch=`).

## Что уже сделано (БТР-80, октябрь 2026)

- `tools/prepcar.mjs` работает с любым числом колёс (углы `<ось><L|R>`), кладёт каждое колесо в узел-держатель в измеренном центре ступицы (у скачанных моделей колёса бывают смещены на сантиметры), отделяет шину от диска по материалу (`tireMaterial` → `tire_<k>`) и вырезает детали подвески из кузова по габаритным коробкам (`parts`). Конфиг и команды для БТР: `assets-src/btr80/README.md`.
- Оригинальные шины модели деформируются нашим шейдером по каждому лучу физики (`tireMaterial.js`: `makeTireMesh`, `setTireContact`; то же в тени); диск не мнётся (всё внутри радиуса диска неподвижно). Так же сделано для Defender, G-Class и Lancia.
- Подвеска БТР из деталей самой модели: рычаги поворачиваются вокруг шарниров на кузове, амортизаторы тянутся (корпус поворачивается вокруг верхней проушины, шток выдвигается), кулак следует за ступицей (`btrModel.js`). Библиотеки деталей для других машин пока нет.
- `tools/rigview.html?car=<id>`: модель без игры, поза подвески и деформация шины задаются руками (`pose`, `isolate`, `hide`, `turret`, `rays`). Для скриншотов подвески снизу (шаг 7).

## Бюджеты

- Модель: до 3–5 МБ после сжатия.
- Звук мотора: 150–400 КБ.
- Ближние детали — полная детализация, дальние — упрощённые уровни.

## Готово, когда

- все тесты машины зелёные;
- скриншоты из набора выглядят правильно: нет дыр, салон виден, фары светятся, подвеска на месте;
- владелец проехал и одобрил (на вехе, не на каждой машине).
