# 09. Техника и архитектура

## Стек

- **three.js** — рендер (WebGL2; WebGPU оценить, `05-graphics.md`).
- **Rapier** — твёрдые тела, столкновения, лучи.
- **Своя физика техники** поверх Rapier (`02-physics.md`).
- **Vite** — сборка. **Trystero** — мультиплеер peer-to-peer.
- Чистый JavaScript (ES-модули). Переход на TypeScript — решение по ходу, если он облегчит параллельную работу агентов над интерфейсами модулей.

## Что остаётся, что переписывается

- **Остаётся и улучшается**: физика машины (`src/vehicle/` — физическая часть), рендер-пайплайн (`src/render/`), небо и атмосфера.
- **Переписывается с нуля**: UI, мир и карта, пайплайн машин, визуальная часть машин, звук.

## Модули и интерфейсы

Каждая область — свой модуль с явным интерфейсом, чтобы параллельные агенты не мешали друг другу:
- **техника**: ввод → шаг физики → состояние (для вида, звука, UI, сети), снимок и восстановление; реализации: колёсная с N осями, позже гусеничная и винтокрылая;
- **мир**: рельеф, поверхности, объекты, вода, погода, подгрузка кусками; запрос «что под точкой» для физики;
- **вид**: машины, мир, свет, пост-обработка;
- **звук**: слушает состояние техники и мира;
- **UI**: читает состояние, отправляет действия, ничего не хранит сам;
- **режимы**: свободная езда, испытания, реплеи, фоторежим, мультиплеер;
- **настройки и данные**: машины, сетапы, рекорды, локализация.

## Мир кусками

- Мир 5×5 км делится на тайлы (например, по 256 м). Вокруг игрока грузятся тайлы с физикой и детальной графикой, дальше — упрощённые.
- Рельеф далеко — упрощённая сетка (CDLOD уже есть), растительность — инстансы и импостеры.
- Тайлы и ассеты кэшируются в браузере (Cache API / service worker), второй запуск почти без загрузки.

## Загрузка и память

- Первая загрузка до возможности ехать — как можно меньше: ядро, район старта, выбранная машина. Цель: до ~15 МБ, остальное в фоне.
- Сейчас стартовый JS около 2 МБ сжатого (большая часть — Rapier), модель машины 1,6–4 МБ.
- Бюджеты видеопамяти и памяти по пресетам. Телефон — отдельный бюджет.

## Детерминизм, снимки, реплеи

- Фиксированный шаг физики 240 Гц уже есть.
- Полный снимок и восстановление состояния: мир Rapier плюс состояние техники.
- Реплей = ввод на каждый шаг плюс периодические снимки (полного бит-в-бит детерминизма между браузерами нет).

## Тесты

- **Физика без браузера**: `npm run simtest` и его наследники, с порогами и кодом выхода (`02-physics.md`).
- **Скриншоты**: headless Chromium (Playwright, уже работает в облачных сессиях) снимает заданные места и экраны; используются для проверки агентами и для отчётов на вехах.
- **Производительность**: фиксированные маршруты камеры, замер времени кадра по системам.
- **CI**: GitHub Actions на каждый PR — сборка, simtest, проверка размера бандла. Сейчас CI нет.
